# LIHIM

**LIHIM** is an anonymous messaging app built to be **safe, secure, and private**.  
It lets users send and receive messages without revealing their identity — a safe space for honest thoughts, confessions, and supportive messages.

---

## ✨ Features

- 🕵️ Send & receive anonymous messages  
- 🔐 Secure message handling  
- 🛡️ Privacy-first design    
- 💬 Confessions & stories

## 🧠 Purpose

LIHIM was created to provide a safe digital space where people can:

- Share thoughts anonymously  
- Send confessions without fear  
- Comfort and support others  
- Express emotions freely without judgment

## 🛠 Tech Stack

- **Backend:** Firebase (Firestore / Auth)  
- **Hosting:** GitHub Pages / Netlify / Vercel
